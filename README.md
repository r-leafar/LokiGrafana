# ASP.NET Minimal API com Grafana Loki (.NET 10)

Este repositório demonstra como criar uma **ASP.NET Minimal API** com **.NET 10** e enviar logs estruturados para o **Grafana Loki** — permitindo centralização e visualização de logs em tempo real.

---

## 📌 Tecnologias Utilizadas

- .NET 10
- ASP.NET Minimal API
- Grafana Loki
- Grafana Alloy
- Grafana
- Docker
- Docker Compose
---

## ▶️ Como Executar
```bash
git clone https://github.com/r-leafar/LokiGrafana.git

cd LokiGrafana

docker compose up -d
```
